## ⚠️ Termination contract — READ FIRST (the rule agents skip)

This is a LOOP, not a one-shot. It ends — and you may {{DONE_ACT}} — **only when a full, demonstrably-thorough round makes ZERO edits to the {{ARTIFACT}}** (a genuine no-op pass). Fixes open new gaps, so **the pass in which you edited the {{ARTIFACT}} is NEVER the last pass** — it MUST be followed by another full round. **The pass SHAPE:** pass 1 reads the WHOLE {{ARTIFACT}}; middle passes (2 … N-1) are SCOPED to the EDITS the prior pass made plus the sections that cross-reference them; the CLOSING pass is a full fresh read — net **1 wide + k scoped + 1 wide**, never scoped-to-exit (the closing full read is the recall mechanism), its finders in a non-author context wherever the loop dispatches finders (`62-using-subagents.md` § Role separation defines independent; a solo pass with no dispatch closes with its own full fresh read). ⚠️ **THE CLOSING PASS IS A RE-DERIVATION PASS — a different METHOD, not just a fresh read, and the
ledger must SAY so.** RE-DERIVE every factual claim — every count, enumeration, and line anchor —
from its primary source; do not re-verify citations (those were verified in earlier rounds, and
re-running the same method reaches the same blind spots). Three classes are invisible to
citation-checking BY CONSTRUCTION: **count-re-derivation** (the cite proves the example, never the
number), **bounded-search-as-total** (a `-N`/`head`/`-A` window read as the population), and
**data-integrity** (a constraint the text asserts and the store does not hold). Two live proofs one
week apart: trade-intelligence (two false claims through TWO no-op stamps) and tryton-crm (SIX
defects through ELEVEN rounds — the sentence prescribing this pass was IN the command and applied
in zero rounds, because nothing detected its absence). So the **Pass Ledger carries a `method`
column** (`citation` | `re-derivation` | `gate`), the exit requires **at least one
`re-derivation` row**, and for a PLAN flipping to CONVERGED `check_convergence.py` REFUSES the flip
without one — the form is machine-checked; running the pass honestly is what the token attests.
Convergence under one method is method-stability, not truth. **Minimum two passes, ALWAYS** — even an edit-free pass 1 must be confirmed by an independent pass 2; accuracy outranks pass-count.

Anti-cheat (mechanical, not vibes): record the {{ARTIFACT}}'s `md5sum` at the **start and end of the final pass**. Identical hash = a real no-op → {{DONE_WORD}}. Different hash = you edited → run another pass. A no-op asserted without matching hashes does not count.{{EXEMPT_NOTE}}

Maintain a numbered **Pass Ledger** and reproduce it verbatim in your report — each row names what that pass actually RE-CHECKED (a verification-only look is labelled `VERIFY`, never numbered as a pass; an `edits: 0` row for a round that never ran is a FABRICATED row, worse than an honest unfinished ledger). You are done **only when the last row reads `edits: 0`** with `md5(start) == md5(end)`. Any last row with `edits > 0` means you owe the next pass — **run it UNPROMPTED, inside THIS invocation**, the moment it is owed; the obligation predates any challenge. Never end the turn on a non-zero row for the operator to re-invoke — **you return control EXACTLY ONCE: at the edit-free, md5-verified no-op.** Three thoughts that each mean *run the next pass now*: "it was already done," "the edit was trivial," "it's obviously clean." The final pass must also have **raised zero candidates** — a pass that raised 3 and refuted all 3 made no edits but is NOT quiet; log every raised candidate in the ledger and run the next pass, each row also recording `new:` (candidates first raised THAT pass — never raised by an earlier one). **Stall circuit-breaker:** 3 consecutive passes with non-decreasing **and nonzero** `new:` counts → STOP with `## BLOCKED: NON-CONVERGENCE` naming the suspected foundation error — measured non-progress means the defect is upstream of the {{ARTIFACT}}'s text (a design claim, a contract); re-ground it, then resume. Not a ceiling: passes stay unbounded while `new:` falls, a refute-everything pass (new: falls to 0 next) never trips it, and an all-zero `new:` streak is convergence, never a stall — the breaker just doesn't fire; DONE still requires the raised-zero quiet pass above. **Probe duty (pass 1 AND the closing pass):** RUN every probe the {{ARTIFACT}} embeds — a probe is a fenced block whose first line begins `$ ` (illustrative fences without that prefix are exempt) — and compare output verbatim; the closing pass runs them AGAIN because middle-pass edits can silently stale a probe that was true at pass 1. A LOAD-BEARING claim (one some step or verdict would change were it false) carrying NO probe is itself a standing finding: "ungrounded claim". **There is NO pass ceiling** — while anything is still being raised or edited, the next pass is owed. The non-quiet stops are exactly TWO — the stall circuit-breaker above, and a per-axis **BLOCKED escalation**: an axis stuck after 3 consecutive reconcile attempts → pause it, surface it to the operator in the report's `## BLOCKED` section (axis + the 3 attempts), keep converging the rest. Never self-exit with an "accepted risk". **Context is never a reason to stop:** the harness AUTO-COMPACTS long conversations and the run continues in the same invocation — keep durable artifacts current and keep going; "low context" filed as BLOCKED is still the named violation, and a heavy remainder is dispatched to fresh subagents, never deferred.
