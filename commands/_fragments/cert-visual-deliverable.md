- **⚠️ VISUAL-DELIVERABLE QA — a visual deliverable's proof is EYES ON THE RENDERED PIXELS.** Structural checks (file exists, format header, HTTP 200, the right hexes in the JSON/CSS, the source SVG's bytes present inside the composed output) prove the pipeline WIRED the right inputs — they do NOT prove the rendered result looks right.
  For EVERY image/PDF/SVG/favicon/video-frame deliverable: RENDER it (rasterize PDFs + SVGs first), then
  INSPECT the pixels with vision (`fabrik-gui` subagents have vision; fan them across artifact classes, adjudicate yourself) against the contract/brand: logo integrity/clipping, palette fidelity, typography actually rendering as the specified face (not a fallback), layout defects, contrast on every surface.
  A deliverable nobody looked at is an UNCHECKED row, not a PASS.
