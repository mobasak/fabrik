# Review probe catalogue

The probes earlier review runs found missing, by when they apply. Read the lines that match the change's SHAPE —
never all of them — before the first pin and while writing the brief. Each is a step, not a check box: execute it,
or name in the brief why the shape does not have it.

## Before the first pin (the lead executes)
- Run the changed artifact end to end when it can run, and check the END STATE a recipe exists to produce, not only
  each step; run a README or usage snippet as a caller would.
- Trace the entry path: the first caller that reaches the fixed function; enumerate every call shape through a new
  branch and every input path of a shared reader.
- Enumerate the fix's input class whole (boundary, empty, unset, mandated, non-dict/non-string, every Unicode
  whitespace class, the real committed files' shapes counted by an independent parser), and each guard's ESCAPE
  VARIANTS in both directions — false green and false red — committing the positive/negative probe list beside it.
- Name the defect's class and grep the whole class (every site, sibling guards, every scaffold type, recursively,
  vendored venvs excluded) before patching one instance; diff sibling implementations side by side.
- One mutant per clause the edit states, written as a literal before/after; re-run every prior mutant after each fix;
  probe each new grader with its mutant.
- Run the repo's structural source graders, every touched test file whole, and the completion gate on the pinned
  files; feed a sample row through every grader that parses the artifact.
- Execute: every factual row of a relayed report, every cross-repo claim and every count in a decision row (with its
  command and denominator), every remedy proposed for a security primitive, a confirmed candidate's premise before
  writing its fix, and a report-adopted fix traced into its consumers.
- Before widening a matcher or heuristic: its fire rate and added-hit precision on the live population, the
  failure-mode asymmetry, and a written residual; before a parity claim, whether the mirror can be exact with the
  dependencies available; before a counted bar changes, drive it over the real series.
- Grep the docs and ledgers for a by-design rule on the subject; resolve an integrity-check exemption against its
  real target; render a fragment edit's consumers to a temp dir and read each.

## The brief's hunt lines (name the ones the shape has)
- Callers and consumers: every caller of a changed exit code, output line or gated script; every consumer of a
  changed prompt output, of import-time side effects, of a flipped Status (generated indexes) or of a renamed name
  (link fields, hand-kept indexes); every gate grading the old name; every outbound sink a production-reaching test
  can touch; every actor touching an RLS table; placeholder resolution per consumer.
- Parsers: the producer's real output contract first, then the parsing model before tokens; lossy cases (duplicate
  keys, ordering, whitespace), regex/strip edges, the request-target grammar for URLs, comment and brace shapes for
  config, the real interpreter (dash) and the parent commit as oracles; a generated file is parsed by its generator's
  format.
- Guards and rules: the guard's equivalence class (must fold, must not), what a replaced guard covered that its
  replacement does not, every exception subclass a new catch admits, false negatives classed plausible vs contrived,
  whether each matcher shortcut is covered by the general path, every rule an overriding sentence overrides, which
  value wins when a new knob meets an existing per-row setting, and the rule's cost on the previous behaviour.
- State and concurrency: who waits on a new lock and behind what; new module-level state reset on every return;
  every value a changed predicate sees from each writer (0 vs NULL); whether a filtered counter keeps its own records;
  which fixture scopes run before an autouse pin; an env-leak fix where `delenv` on an absent key records nothing.
- Failure paths: what a fix does when its own fallback fails; the configuration-failure path; a fail-soft mail or
  report path fed malformed stored data; a shell chain whose failing step must fail the chain; a dry-run and write
  path diffed field by field; a validator's direct-call path, not only the wire.
- Surfaces: every connection a guarded module opens; every field a new serializer emits; argparse edges of a new
  flag; machine-parsed section markers; a literal pipe inside a table cell; a moved reference and which sentence
  branch reaches it; each mechanism claim at every lane or version it names; `git check-ignore` on the bare directory.
- The premise: the authoritative seat attacks the work item's premise and a ported heuristic's premise, not only the
  implementation; ask whether an existing mechanism or fragment already covers the class, and whether the check fits
  a boundary the data already has; edited prose is checked against its rule pack's SCOPE line.

## Graders
- Grade the PROPERTY across every example, never one spelling; a new assertion must fail when its subject is absent
  (an absence assertion over never-written state is vacuous); a grader EXECUTES an executable subject, through the
  real production adapter and the consumer's entry point (the command's output, not the function), never reads it.
- Each parser-output shape owes its own red; a config or regex grader is graded by running the tool on mutated inputs;
  a red branch of a new procedure step is executed as well as the green; a boundary fix tests both sides with the
  exact message; a numeric bound is derived in its comment and graded at both edges, with the determining input
  varied first.
- Mutants: one per new comparison or constant, each anchored on a token the formatter cannot rewrap, the mutated line
  shown changed before a green is trusted, survivors reported; a regression test fails when the caller is reverted.
- Test hygiene: a test stub records what it RECEIVED; a timing test is repeated 10× under its mutation; isolation is
  proven by a reversed-order run and by removing the fixture; a state-mutating grader leaves nothing on teardown;
  non-ASCII literals are checked by bytes; the whole suite directory of a changed test runs; a golden value is pinned
  after printing its matched span; a byte-identical refactor gets a HEAD-vs-new differential harness.

## Prose and docs fixes
- A rule already in a fragment is quoted in its own words and pointed at; a ported rule is re-derived against this
  command's machinery; a parser rule is stated positively, not as a terminator list.
- After the edit: rewrap the whole paragraph by tool; re-read an inserted sentence with the one after it; a
  long-line replacement keeps its neighbours' opening clauses; re-read a cited range after rewording its citation.
- Sweep: a corrected claim or quote across every file the change touched (test docstrings included), whitespace- and
  wrap-normalised; every statement of a changed number or count in the whole file; same-subject lines in the pack,
  doc summary rows and artifact generators that restate it; residue words of a flipped decision.
- Claims: every factual sentence of an edited paragraph re-derived; every clause on a count-fixed line checked
  against the code; a count cites the command (with its range) and the line that holds it, a measured count names
  its population, a live value is a timestamped snapshot; an unverified hand-derived enumeration is deleted.
- A site a round re-opened, or a bullet wrong two rounds running, is rewritten or deleted whole, never patched again.

## Seat isolation
- Seats copy the pin to scratch and assert its md5s first; run tests in a throwaway checkout at the pinned SHA
  (`git clone --local`, never `git worktree add` on the shared `.git`, never a `PYTHONPATH` copy), with that copy's
  `.venv` python, `.env` and built dist; ruff and mypy from the repo root with the hub config; exact test node ids.
- No `uv`/`pip`, no live API key outside the suite's fixtures, no writing verb outside scratch; one grep form; large
  output goes to the seat's scratch first; the adjudication authority (CLAUDE.md, the packs) is read at the pin; a
  claim only the home directory can settle is recorded up front for the lead.
- Every file a grader reads is pinned, the uncommitted module under test included; a "nothing changed for readers"
  claim is proven on a pinned input; a concurrent sibling run on a shared DB is a known false red; a seen-red on a
  DB-writing script names its sandbox.

## Loop bookkeeping
- Run `dispatch_headroom.py` before the pin and stamp its SEATS in the same call; a SEATS 0 on a box cap is an in-turn
  wait (re-check on each nudge); while seats are out, build the next fixes in a scratch copy, never the pinned files;
  write the Workflow args JSON to scratch, and resume an interrupted Workflow with `resumeFromRunId`.
- A round is recorded only after every candidate is read; `confirmed` counts DEFECTS, never checks passed, and a
  gate-caught defect counts; a delta brief lists the exact mutant ids executed and checks ROUTED claims for routing
  only; a one-hop edit found mid-fix is named in round 1's scope; the slice ledger is round 1's claim count even at
  zero confirmed.
- Lint or format findings are compared against HEAD before they are reported, and tests re-run after the last
  lint fix; read the callee before confirming a wrong-method finding; run the files a reader names, not every grep hit.
- A RECORDED residue whose surface is another beat's is mailed at the close; shared-ledger hunks land before the
  closing pass; the completion gate runs before the terminal round is recorded.
