# Excel File Generation Guide for AI Agents

**Last Updated:** 2026-03-06
**Source:** Lessons learned from Candle Test Tracker development

## Critical Rules (MUST FOLLOW)

| Rule | Why | Impact |
|------|-----|--------|
| **No full column refs in formulas** | Excel corruption | File won't open |
| **No text starting with `=`** | Interpreted as invalid formula | File won't open |
| **Data validation ≤ 255 chars** | Excel limit | Validation ignored or corruption |
| **Use bounded ranges** | Prevents recalc issues | Performance + corruption |

---

## 1. Full Column References

### The Problem

Full column references like `A:A`, `H:H`, `$A:$AI` in formulas cause Excel to report corruption when the file is generated by openpyxl.

**Excel error:** "We found a problem with some content in '[filename].xlsx'. Do you want us to try to recover as much as we can?"

### Bad Examples (DO NOT USE)

```python
# WRONG - Full column references
ws.cell(row, 35).value = f'=COUNTIF(Checkpoints!$A:$A,A{row})'
ws.cell(row, 8).value = f'=VLOOKUP(A{row},Tests!$A:$AI,20,FALSE)'

# WRONG - Dashboard formulas
("Total Tests", '=COUNTA(Tests!A:A)-1'),
("Active Tests", '=COUNTIF(Tests!H:H,"IN_PROGRESS")'),
```

### Good Examples (USE THESE)

```python
# CORRECT - Bounded ranges with specific rows
ws.cell(row, 35).value = f'=COUNTIF(Checkpoints!$A$1:$A$502,A{row})'
ws.cell(row, 8).value = f'=VLOOKUP(A{row},Tests!$A$1:$AI$502,20,FALSE)'

# CORRECT - Dashboard formulas with bounded ranges
("Total Tests", '=COUNTA(Tests!$A$1:$A$502)-1'),
("Active Tests", '=COUNTIF(Tests!$H$1:$H$502,"IN_PROGRESS")'),
```

### Formula Types Affected

| Formula | Bad Pattern | Good Pattern |
|---------|-------------|--------------|
| `VLOOKUP` | `Tests!$A:$Z` | `Tests!$A$1:$Z$500` |
| `COUNTIF` | `Sheet!A:A` | `Sheet!$A$1:$A$500` |
| `COUNTA` | `A:A` | `$A$1:$A$500` |
| `SUMIF` | `B:B` | `$B$1:$B$500` |
| `INDEX/MATCH` | `C:C` | `$C$1:$C$500` |
| `COUNTIFS` | `X:X` | `$X$1:$X$500` |

### Range Sizing Guidelines

- **Small datasets (< 100 rows):** Use 200 rows buffer → `$A$1:$A$200`
- **Medium datasets (100-500 rows):** Use 502 rows → `$A$1:$A$502`
- **Large datasets (500+ rows):** Use actual max + 100 → `$A$1:$A$1100`
- **Header row:** Always start at row 1 (`$A$1`) even if data starts at row 2

## 2. Text Interpreted as Formulas

### The Problem

Any cell content starting with `=` is interpreted as a formula by Excel. If the text after `=` is not valid formula syntax, Excel reports corruption.

**Common culprits:**
- Section headers like `=== TITLE ===`
- Decorative separators like `======`
- Markdown-style formatting `== Heading ==`

### Bad Examples (DO NOT USE)

```python
# WRONG - Will be interpreted as invalid formula
content = [
    ("=== GETTING STARTED ===", "", ""),
    ("=== DAILY WORKFLOW ===", "", ""),
    ("== SECTION HEADER ==", "", ""),
]
```

### Good Examples (USE THESE)

```python
# CORRECT - Use different delimiters
content = [
    ("--- GETTING STARTED ---", "", ""),
    ("--- DAILY WORKFLOW ---", "", ""),
    (">> SECTION HEADER <<", "", ""),
]

# CORRECT - Or use plain text headers
content = [
    ("GETTING STARTED", "", ""),
    ("DAILY WORKFLOW", "", ""),
    ("SECTION HEADER", "", ""),
]

# CORRECT - Or escape with single quote (displays without quote)
content = [
    ("'=== GETTING STARTED ===", "", ""),
]
```

### Safe Header Patterns

| Pattern | Safe? | Notes |
|---------|-------|-------|
| `=== TITLE ===` | ❌ NO | Interpreted as formula |
| `--- TITLE ---` | ✅ YES | Safe delimiter |
| `>> TITLE <<` | ✅ YES | Safe delimiter |
| `** TITLE **` | ✅ YES | Safe delimiter |
| `[[ TITLE ]]` | ✅ YES | Safe delimiter |
| `TITLE` | ✅ YES | Plain text |
| `'=== TITLE ===` | ✅ YES | Escaped with quote |

## 3. Data Validation Limits

### The Problem

Excel data validation formulas have a **255 character limit**. Exceeding this causes:
- Silent validation failure (dropdown doesn't work)
- Potential file corruption
- "Repaired" message on file open

### Bad Example (DO NOT USE)

```python
# WRONG - This string is 280+ characters
wick_options = "TCR 18,TCR 21,TCR 24,TCR 27,TCR 30,TCR 33,TCR 36,TCR 39,ST 18,ST 21,ST 24,ST 27,ST 30,ST 33,ST 36,ST 39,Stabilo 10,Stabilo 12,Stabilo 14,Stabilo 16,Stabilo 18,Stabilo 20,Stabilo 22,Stabilo 24,Stabilo 26"
dv = DataValidation(type="list", formula1=f'"{wick_options}"', allow_blank=True)
```

### Good Examples (USE THESE)

**Option 1: Shorten option names**
```python
# CORRECT - Shorter names (147 chars)
tcr = ",".join([f"TCR{s}" for s in [18, 21, 24, 27, 30, 33, 36, 39]])
st = ",".join([f"ST{s}" for s in [18, 21, 24, 27, 30, 33, 36, 39]])
stabilo = ",".join([f"Stabilo{s}" for s in [10, 12, 14, 16, 18, 20]])
wick_options = f"{tcr},{st},{stabilo}"  # 147 chars - SAFE
dv = DataValidation(type="list", formula1=f'"{wick_options}"', allow_blank=True)
```

**Option 2: Use a named range from helper column**
```python
# CORRECT - Reference a range instead of inline list
# First, populate options in a hidden column or sheet
for row, option in enumerate(all_options, 2):
    ws.cell(row, 50, option)  # Hidden column AX

# Define named range
from openpyxl.workbook.defined_name import DefinedName
defn = DefinedName("WickOptions", attr_text="Sheet!$AX$2:$AX$50")
wb.defined_names.add(defn)

# Use named range in validation
dv = DataValidation(type="list", formula1="=WickOptions", allow_blank=True)
```

**Option 3: Reference a list sheet**
```python
# CORRECT - Reference cells on another sheet
dv = DataValidation(type="list", formula1="Options!$A$2:$A$50", allow_blank=True)
```

### Character Count Check

```python
def validate_dv_length(formula: str) -> bool:
    """Check if data validation formula is within Excel's 255 char limit."""
    # Remove the surrounding quotes if present
    content = formula.strip('"')
    if len(content) > 255:
        print(f"WARNING: Data validation formula is {len(content)} chars (max 255)")
        return False
    return True
```

## 4. Cross-Sheet References

### The Problem

Cross-sheet references in data validations and formulas must use correct syntax. Common issues:
- Missing sheet name quotes for sheets with spaces
- Full column references (see section 1)
- Invalid sheet names

### Bad Examples (DO NOT USE)

```python
# WRONG - Sheet name with space, no quotes
dv = DataValidation(type="list", formula1="My Sheet!$A$2:$A$100")

# WRONG - Full column reference
ws.cell(2, 5).value = "=VLOOKUP(A2,OtherSheet!A:Z,3,FALSE)"
```

### Good Examples (USE THESE)

```python
# CORRECT - Quote sheet names with spaces
dv = DataValidation(type="list", formula1="'My Sheet'!$A$2:$A$100")

# CORRECT - Bounded range
ws.cell(2, 5).value = "=VLOOKUP(A2,OtherSheet!$A$1:$Z$500,3,FALSE)"

# CORRECT - Simple sheet names don't need quotes
dv = DataValidation(type="list", formula1="Options!$A$2:$A$100")
```

### Sheet Naming Rules

| Character | Allowed in Sheet Name? | Needs Quoting? |
|-----------|------------------------|----------------|
| Space | ✅ Yes | ✅ Yes |
| Underscore `_` | ✅ Yes | ❌ No |
| Hyphen `-` | ✅ Yes | ❌ No |
| Period `.` | ✅ Yes | ✅ Yes |
| Colon `:` | ❌ No | N/A |
| Slash `/\` | ❌ No | N/A |
| Brackets `[]` | ❌ No | N/A |

**Best Practice:** Use underscores instead of spaces in sheet names (e.g., `User_Guide` not `User Guide`).

## 5. Named Ranges

### The Problem

Named ranges created via openpyxl can cause issues if:
- The name conflicts with cell references (e.g., `A1`, `R1C1`)
- The range formula is invalid
- The scope is incorrect

### Good Examples (USE THESE)

```python
from openpyxl.workbook.defined_name import DefinedName

# CORRECT - Clear, descriptive name with sheet scope
defn = DefinedName(
    name="WickOptions",
    attr_text="Wick_Brands!$A$2:$A$50"
)
wb.defined_names.add(defn)

# CORRECT - Workbook-level constant
defn = DefinedName(
    name="FMP_TOLERANCE",
    attr_text="2"  # Numeric constant
)
wb.defined_names.add(defn)

# CORRECT - Reference to settings cell
defn = DefinedName(
    name="SOOT_THRESHOLD",
    attr_text="Settings!$B$3"
)
wb.defined_names.add(defn)
```

### Named Range Rules

| Rule | Example |
|------|---------|
| No spaces | `WickOptions` not `Wick Options` |
| No cell-like names | `MyRange` not `A1` or `R1` |
| Alphanumeric + underscore | `Wax_Suppliers_List` |
| Max 255 characters | Keep names short |
| Case insensitive | `WICKS` = `wicks` = `Wicks` |

## 6. VBA Code Considerations

### The Problem

When generating `.xlsm` files or providing VBA code for users to import:
- VBA code stored in cells (backup) is just text - won't cause formula issues
- But full column references in VBA code DO work (unlike in formulas)
- Users must save as `.xlsm` for macros to work

### VBA Best Practices

```vba
' GOOD - VBA can use full column references (no corruption issue)
countToday = Application.CountIf(ws.Range("A:A"), prefix & "*")

' BETTER - But bounded ranges are still more efficient
countToday = Application.CountIf(ws.Range("A1:A500"), prefix & "*")

' GOOD - Dynamic last row detection
lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
countToday = Application.CountIf(ws.Range("A1:A" & lastRow), prefix & "*")
```

### .xlsx vs .xlsm

| Feature | .xlsx | .xlsm |
|---------|-------|-------|
| Formulas | ✅ Yes | ✅ Yes |
| Data Validation | ✅ Yes | ✅ Yes |
| Conditional Formatting | ✅ Yes | ✅ Yes |
| VBA Macros | ❌ No | ✅ Yes |
| File Size | Smaller | Larger |

**Workflow:**
1. Generate `.xlsx` with openpyxl (can't embed VBA)
2. Provide `.bas` file with VBA code
3. User saves as `.xlsm` and imports VBA module

## Verification Checklist

Before delivering any Excel file, verify:

### Automated Checks (Python)

```python
import zipfile
import xml.etree.ElementTree as ET
import re

def verify_excel_file(xlsx_path: str) -> list[str]:
    """Verify Excel file for common corruption issues."""
    issues = []

    with zipfile.ZipFile(xlsx_path) as z:
        for name in z.namelist():
            if 'sheet' in name and name.endswith('.xml'):
                content = z.read(name).decode('utf-8')
                root = ET.fromstring(content.encode())
                ns = {'main': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'}

                # Check formulas only (not text content)
                for formula in root.findall('.//main:f', ns):
                    text = formula.text or ''

                    # Issue 1: Full column references
                    if re.search(r'[A-Z]+:[A-Z]+(?!\d)', text):
                        issues.append(f"{name}: Full column ref: {text[:60]}")

                    # Issue 2: Text as formula (=== patterns)
                    if text.startswith('=') and '=' in text[1:3]:
                        issues.append(f"{name}: Text as formula: {text[:40]}")

    return issues

# Usage
issues = verify_excel_file('output.xlsx')
if issues:
    for issue in issues:
        print(f"ERROR: {issue}")
else:
    print("✓ File passed verification")
```

### Manual Checklist

- [ ] All `VLOOKUP`, `COUNTIF`, `COUNTA`, `SUMIF` use bounded ranges
- [ ] No text content starts with `=`
- [ ] Data validation formulas ≤ 255 characters
- [ ] Sheet names use underscores (not spaces)
- [ ] Named ranges don't conflict with cell references
- [ ] Cross-sheet references quote sheet names if needed
- [ ] File opens without "repair" prompt in Excel

## Debugging Excel Corruption

When you get "We found a problem with some content":

### Step 1: Inspect the XML

```python
import zipfile

with zipfile.ZipFile('problem_file.xlsx') as z:
    # List all files in the archive
    for name in z.namelist():
        print(name)

    # Read a specific sheet
    content = z.read('xl/worksheets/sheet1.xml').decode('utf-8')
    print(content[:2000])  # First 2000 chars
```

### Step 2: Search for Problematic Patterns

```python
import re

# Search for full column references
full_col_pattern = r'[A-Z]+:[A-Z]+(?!\d)'
matches = re.findall(full_col_pattern, content)
print(f"Full column refs: {matches}")

# Search for formula-like text
formula_text_pattern = r'<f>===.*?</f>'
matches = re.findall(formula_text_pattern, content)
print(f"Text as formula: {matches}")
```

### Step 3: Check Data Validations

```python
# Data validations are in xl/worksheets/sheet1.xml
# Look for <dataValidation> elements
dv_content = z.read('xl/worksheets/sheet1.xml').decode('utf-8')
if 'dataValidation' in dv_content:
    # Extract and check formula1 lengths
    import xml.etree.ElementTree as ET
    root = ET.fromstring(dv_content)
    ns = {'main': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'}
    for dv in root.findall('.//main:dataValidation', ns):
        formula = dv.get('formula1', '')
        print(f"DV formula ({len(formula)} chars): {formula[:50]}...")
```

### Step 4: Let Excel Repair and Compare

1. Click "Yes" to let Excel repair the file
2. Save the repaired file as `repaired.xlsx`
3. Compare XML between original and repaired:

```bash
# Extract both files
unzip problem_file.xlsx -d original/
unzip repaired.xlsx -d repaired/

# Compare sheet XMLs
diff original/xl/worksheets/sheet1.xml repaired/xl/worksheets/sheet1.xml
```
