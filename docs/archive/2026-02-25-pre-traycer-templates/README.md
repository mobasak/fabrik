# Pre-Traycer Templates (Archived)

**Archived:** 2026-02-25

## Why Archived

These templates are superseded by Traycer as the planning authority:

- `PHASE_TEMPLATE.md` — Manual phase tracking replaced by Traycer Phases
- `TASKS_TEMPLATE.md` — Manual dashboard replaced by Traycer Phase tracking
- `implementation-plan-template.md` — Manual droid `--use-spec` plans replaced by Traycer-generated specs

## What Replaced Them

- **Planning:** Traycer Phases (via Traycer IDE Extension or CLI)
- **Spec generation:** Traycer exports specs dynamically (no static template needed)
- **Coder workflow:** Read Traycer-generated spec → implement → run Final Gate → Kilo review → Traycer verification

## For New Projects

Use Traycer to create phases and specs. Do NOT recreate these templates.
