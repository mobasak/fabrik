## Behavior Contract
- **Given** a registered builder with a transcript, **When** `agents_up.sh --print <R>` runs, **Then** its `run` line resumes with `--settings` carrying `skillOverrides.auto-mode-setup=off` and `spinnerTipsEnabled=false`, and its env carries `CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1` (scripts/sysadmin/agents_up.sh:494; spec § The delta D3)
- **Given** a resolved new builder, **When** `agents_up.sh --pane-cmd <R> <name> <sid> --new` runs, **Then** stdout is one command with `--session-id <sid>` and the first prompt; an unresolved pair, a missing worktree, or `--new` on a sid with a transcript exits 2 with no command printed (scripts/sysadmin/agents_up.sh:344-351; spec § The delta D1; plan-review pass 1, B6)
- **Given** a spawner-bound builder whose sid has no transcript in any project folder, **When** `--print` runs, **Then** its run line uses `--session-id`, and with `<sid>.jsonl` under any other project folder it uses `--resume` (spec § The delta D2; W-14219e6f point 13; plan-review pass 1, B14)
- **Given** a first prompt containing a backtick, a double quote and a `$`, **When** the pane command is run by `/bin/sh -c` against a fake claude that prints its argv, **Then** the prompt arrives byte-for-byte (scripts/sysadmin/agents_up.sh:451-453; plan-review pass 1, B7)
- **Given** a registry naming only a coordinator, or bindings with no builder worktree, **When** the launcher runs, **Then** it exits 3, while a malformed registry row, an unreadable ledger, or an unreadable identity store in a registry-less repo exits 2 (scripts/sysadmin/agents_up.sh:160-186; spec § Contract deltas; plan-review pass 1, B5)
- **Given** every resolved worktree removed between resolve and launch, **When** the grid starts, **Then** nothing launches and it exits 2 with the emptied-grid message (scripts/sysadmin/agents_up.sh:595-623; spec § The delta, Folded residue)
- **Given** `--pane-cmd … --new --coordinator coord-a --item W-1a2b3c4d`, and separately `FABRIK_SPAWN_NAME=b-1 FABRIK_SPAWN_COORDINATOR=coord-a` on a `--print`, **When** each runs, **Then** b-1's first prompt names coordinator `coord-a` (and W-1a2b3c4d in the first), another builder's prompt does not, and `--coordinator 'x y'` exits 2 (panel PO1, PO2)
- **Given** claude processes `-n infra` (cwd elsewhere) and `-n infra-2` (cwd infra-2's worktree), none with `--resume`, **When** `--print` runs, **Then** infra-2 reads `running` and infra does not (scripts/sysadmin/agents_up.sh:441-449; spec § The delta D9; plan-review pass 1, B4)
