# Cloud audit: nonatomic-state-writes

- **Class:** every write of a shared state, ledger, lock or registry file (under `~/.claude/state`, `.fabrik/`, `/opt/fabrik-mail`, or a json/jsonl/yaml the code reads back) done with `open(p,'w')` / `write_text` / `write_bytes` and no temp file + `os.replace`, so a crash or a concurrent reader sees a truncated file.
- **Date:** 2026-10-29. Read-only audit of the checkout at branch `claude/audit-nonatomic-state-writes` (no code changed).
- **Population:** 9187 tracked files; 1202 tracked `.py`; 113 tracked `.sh`/`.bash`. Searched 480 tracked `.py` files (everything except `tests/`, `templates/`), giving 992 call-shape matches. Excluded from the verdict tally: `scripts/tests`, `scripts/kilo-benchmarks/tests`, `scripts/sysadmin/test_*` (tests), `scripts/.archive`, `scripts/archived` (dead code, 81 matches), `scripts/.scratch`, `docs/reference/research` (one-off mining script). That leaves 439 in-scope matches plus `scaffold.py`'s 165 = 604 counted below. The tally unit is a match line, so counts are sites, not files; the last SAFE row is a difference, not a hand count.
- **Search commands** (method 1, call shape; method 2, read the wrapping helpers; method 3, shell):
  - `git ls-files '*.py' | grep -vE '^(tests/|templates/)' | xargs grep -nE "write_text\(|\.write_bytes\(|open\([^)]*['\"](w|wb|a|a\+|w\+|x)['\"]|json\.dump\(|os\.open\(|\.touch\("`
  - triage script (python3, repo files only): for each match, look ±12 lines for `os.replace|.replace(x|os.rename|.rename(|mkstemp|_atomic|atomic_write|_write_atomic`; matches with none were read by hand together with their readers (`grep -n 'read_text\|json.load' <file>`).
  - wrapper search: `grep -nE 'os\.replace|\.replace\(|os\.rename|mkstemp|NamedTemporaryFile|def .*atomic'` over the same files, to find the atomic helpers (`_write_json_atomic`, `_atomic_write`, `_atomic_copy`, `_atomic_text`, `_write_atomic`) and check who uses them.
  - shell: `git ls-files '*.sh' '*.bash'` scanned for redirects (`>`, `tee`) onto state/ledger/lock/stamp/json/pid names: 113 files, 5 hits, all heredoc installers (`bootstrap-hub.sh:674,1648`), a pid file (`archived/kilo_model_sync_startup.sh:32`), a `.ready` marker (`feedback_watch_arm.sh:71`) and a test fixture: none is shared read-back state.
- **Not covered:** `O_APPEND`/`open('a')` writes (partial-line appends, a different failure) and write sites generated into remote shell snippets beyond the two in `src/fabrik/drivers/`. `libs/` was searched (its matches are in the tally); nothing in it was REAL.
