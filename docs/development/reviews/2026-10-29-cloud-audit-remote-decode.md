# Cloud audit: remote-decode (strict decode of external process output)

- **Class:** a subprocess call whose output is decoded strictly (`text=True`, `universal_newlines=True`, or `.decode()` with no `errors=`), so one non-UTF-8 byte from a REMOTE or external process raises `UnicodeDecodeError`.
- **Date:** 2026-10-29. Read-only audit; no code was changed.
- **Branch / checkout:** `claude/audit-remote-decode`, cloud clone of `mobasak/fabrik`; every `path:line` is from this checkout.
- **Population searched:** all 1202 tracked `*.py` files (of 9,187 tracked files; `git ls-files '*.py'`). 1,201 parsed with `ast`; `src/fabrik/drivers/postgres.py` failed to parse under the host Python (nested f-string at :1730) and was searched by `git grep` and read by hand instead. Also read: the 24 files that name `ssh`/`scp`/`rsync` (every `subprocess` call in them listed with its decode kwargs), the wrappers that take a `text=` argument (`scripts/utils/subprocess_helper.py:90`) and their callers, and every non-test `.decode()` hit.
- **Counts of the AST pass:** 1449 strict text-mode calls (no `encoding=`/`errors=`): 323 in production code, 46 in archived code (`.archive/`, `archived/`), 1080 in `tests/` or `test_*.py` files (overlap between archived and test files is why these do not sum). 146 strict `.decode()` calls: 75 outside tests and archives, of which only the ones decoding subprocess output are tabled; the rest decode files, HTTP bodies, base64 or `encode(...)` round trips and are not in the class. A further 30 text-mode calls already pass `errors=`/`encoding=` and are not tabled.
- **Not tabled:** the 1080 test-harness calls and 63 test `.decode()` calls (the harness runs our own fakes, a failure there is a red test, not a production fault). `tests/test_ssh_decode_outside_driver.py` (D-1298) is the grader for the already-fixed package sites.
- **Search commands:**
  - `git ls-files '*.py'` (1,202 files), then an `ast.walk` pass over each file for `Call` nodes named `run|check_output|Popen|check_call|call|getoutput|getstatusoutput|popen` with `text=True` or `universal_newlines=True` and neither `encoding` nor `errors`; and for `.decode()` with at most one positional argument and no `errors`.
  - A second `ast` pass for any other call carrying `text=`/`universal_newlines=` (finds wrappers; only `scripts/container_images.py:299,550` were wrapper callers).
  - `git grep -nE 'text\s*=\s*True|universal_newlines\s*=\s*True' -- '*.py'` (1,509 hits in the same population, tests included) and `git grep -nE '\.decode\(' -- '*.py'` (307), as a cross-check on the AST counts.
  - `git grep -lE 'subprocess|check_output|Popen|asyncssh|paramiko|os\.popen' -- '*.py'` (577 files); `git grep` for `asyncssh|paramiko|pexpect|os.popen|getoutput` (only `scripts/kilo_terminal_runner.py` uses pexpect, with `encoding=None` and an incremental decoder, not strict).
  - A per-file `ast` listing of every `subprocess` call in the 24 ssh/scp/rsync files, to catch bytes-returning wrappers that decode later (`src/fabrik/orchestrator/vultr_provision.py:109,154,388` compare bytes; `libs/alerting/apprise.py:115`, `scripts/sysadmin/vps1_cpu_limits.py:168,316,358,459,489`, `scripts/sysadmin/vps1_ocoron_removal.py:182`, `src/fabrik/drivers/dns.py:193,323`, `src/fabrik/drivers/preflight.py:354`, `scripts/sysadmin/operator_setup.py:425` all use `errors="replace"` or catch `UnicodeDecodeError`, so they are outside the class and not tabled).
- **Verdict key:** REAL = a caller can hit it, the cell names the line that makes it reachable. SAFE = the cell says why. UNSURE = the cell says what would settle it. A "REAL" here means the strict decode is reachable and either raises or silently loses the data; the cell says which.
- **Reachability of git rows:** a git call decodes paths, ref names and commit text, so it fails only if one of those holds a non-UTF-8 byte. Measured on this clone with `python3` over `git ls-files -z` (0 of 9,187 paths not UTF-8) and `git log --all --format=%B` (356 commits, 0 bad bytes); the 40-odd fleet repos under `/opt` were not measured (no access from this clone), hence UNSURE not SAFE.
- **Relation to existing work:** D-1298 (`docs/DECISIONS.md:26`) fixed five package sites (`audit._ssh_check`, `vultr_drill`, the creds scp, `preflight`) and filed W-d67ff76d for five standalone scripts; five REAL rows below are those five (the item cites `vps1_pg_scoped_logins.py:132`, the call is now at :134); the other four REAL rows (`audit_all_registrars.py:169`, `incident_context.py:35`, `proof_run.py:524`, `libs/subagents/tools.py:281`) are not in that item.
