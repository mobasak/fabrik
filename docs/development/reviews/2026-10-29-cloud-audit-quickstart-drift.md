# Audit — quickstart-drift (docs/QUICKSTART.md + docs/CONFIGURATION.md vs the real CLI and env vars)

- **Class:** every command, flag and example in `docs/QUICKSTART.md` (192 lines) and `docs/CONFIGURATION.md` (1182 lines) that does not match the real CLI (`src/fabrik/cli.py`, click; the only `cli*.py` — 3905 lines, 1 group + 29 top-level commands/groups) or the env vars the code reads, and every real CLI command / env var those two docs omit.
- **Date:** 2026-10-29. Read-only audit; no other file changed.
- **Population searched:**
  - CLI: all 30 top-level click registrations in `src/fabrik/cli.py` (29 visible + hidden `new`) plus their 30 subcommands (`preplan`, `ai`, `domain`, `seo`, `vultr`, `gpu`, empty `content`), versus every `fabrik <verb>` and `--flag` in the two docs (QUICKSTART: 20 distinct verbs/forms; CONFIGURATION: 12).
  - Env vars: 79 `.py` files under `src/` (104 distinct env names read), versus 194 UPPER_SNAKE tokens in the two docs; the 194 doc tokens were also grepped against 1994 tracked non-doc, non-`.md` files repo-wide (12 have zero hits).
  - Limit: the env-var half is a src/-scoped scan of the code's own reads. CONFIGURATION.md also documents `scripts/`, `libs/` and fabrik-lib vars. For those, the repo-wide grep (tokens with ≥1 hit anywhere) was the only check, so they are not individually verified as "read".
- **Commands used:** `python3 /tmp/ast_cli.py` (ast walk of `cli.py` decorators → command/option table); regex scan of `src/**/*.py` for `getenv|environ.get|environ[...]|envvar=` plus `*env*("NAME")` wrappers (catches `get_env`); `grep -noE 'fabrik [a-z-]+'` on both docs; a doc-token × `git ls-files` word-boundary grep; direct reads of `cli.py:700-790, 1295-1330, 2040-2110, 2209-2240`, `config.py`, `orchestrator/__init__.py:420-470`, `orchestrator/secrets.py:60-137`, `orchestrator/infrastructure.py:162-173`. Verdicts below cite those lines.
