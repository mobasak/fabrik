## D2 — the class behind D1 (CONFIRMED, fixed at root)

D1 was not an isolated slip. **Three probes this session reported "absent" from a path I never
confirmed existed:**

| # | Probe | Path I used | Real path | What I reported | Truth |
|---|---|---|---|---|---|
| 1 | gatus | `/opt/gatus/config.yaml` | `/opt/monitoring/configs/gatus/apps/tryton-crm.yaml` (bind mount) | `0 refs` | 2 refs |
| 2 | backrest | `ls /opt/backrest/` | `/opt/backrest/config/config.json` | `0 refs` | 6 refs |
| 3 | route | bare `/activities` | `/internal/v1/activities` | `404 = FAIL` | 401, correctly guarded |

**Signature:** a hardcoded path that does not exist yields `0`, and `0` is reported as *absent*. A
count whose search space was never confirmed is indistinguishable from having looked nowhere — the
`denominator-honesty` marker, applied to filesystem and route probes rather than to greps.

**Root fix** (`battery.sh`): every filesystem probe now routes through `refs()`, which **asserts the
path resolves before counting** and emits a distinct token otherwise:

```sh
refs() {  # <label> <pattern> <path>...
  for _p in "$@"; do sudo test -e "$_p" && _found="$_found $_p"; done
  [ -z "$_found" ] && { echo "  $_label: PATH-NOT-FOUND (searched:$* ) — NOT a zero, the probe is wrong"; return; }
  _n=$(sudo grep -rci "$_pat" $_found | awk -F: '{s+=$NF} END {print s+0}')
  echo "  $_label: $_n refs in$_found"
}
```

**Proven on the live box this run** — each line names the path it actually searched:

```
  gatus: 2 refs in /opt/monitoring/configs/gatus/apps/tryton-crm.yaml
  backrest: 6 refs in /opt/backrest/config/config.json
  prometheus: 1 refs in /opt/monitoring/configs/prometheus/prometheus.yml
```

The nonexistent alternates passed in the same call (`/opt/gatus/config.yaml`, `/opt/prometheus/…`)
were **skipped, not counted as zero** — which is the whole behavioural difference.

## D3 — my own D2 fix fails OPEN on a grep error (CONFIRMED, fixed)

Found in Pass 2, only because the rubric's FLOOR injected the fail-closed invariant.

The first `refs()` I wrote asserted the path existed, then did:

```sh
_n=$(sudo grep -rci "$_pat" $_found 2>/dev/null | awk -F: '{s+=$NF} END {print s+0}')
```

`2>/dev/null` swallows a `grep` failure (permission denied, unreadable file), and `print s+0` then
emits a clean `0`. **So the exact defect I was fixing — a zero that means "the probe broke", not "found
none" — survived inside my own fix, one layer down.** The path assertion closed the missing-path case
and left the failed-read case wide open.

Fixed by checking grep's exit status and emitting `GREP-FAILED` rather than a count. A probe that
cannot distinguish "no matches" from "could not look" is the same defect wearing a different hat.
