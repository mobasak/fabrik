# Documentation Policy

**Rule:** Update existing docs, don't create new ones.

## Master Documents (Update These)

- `docs/TROUBLESHOOTING.md` - All infrastructure/ops issues
- `docs/DEPLOYMENT_ARCHITECTURE.md` - Deployment, Docker, hosting
- `docs/CONFIGURATION.md` - Environment variables, credentials
- `README.md` - Project overview, quick start

## Blocked Directories

- `docs/infrastructure/` - Use TROUBLESHOOTING.md
- `docs/operations/` - Use DEPLOYMENT_ARCHITECTURE.md

## Adding New Content

1. Identify topic
2. Find existing file: `grep -r "topic" docs/*.md`
3. Add section to existing file
4. Update table of contents if needed

**Enforcement:** `scripts/enforcement/check_doc_sprawl.py`
